Cartera de proyectos

Seguimiento local

Varios planes de proyecto (de una o varias empresas y sectores) guardados en tu propio proyecto de Supabase. Quien tenga acceso ve el tablero siempre actualizado: la página revisa cambios cada minuto. Cada plan lo ven solo su dueño y los correos a los que se comparte; los datos no van cifrados de punta a punta (el administrador de tu proyecto Supabase puede leerlos).

1. Conectar el proyecto

Si te mandaron un enlace, ya viene conectado. Si eres el dueño, escribe la URL del proyecto y su clave pública (Project Settings → API Keys → «publishable key»; también sirve la «anon» antigua). Nunca uses la «secret» ni «service_role». Ambos datos son públicos por diseño y se guardan solo en este navegador.

2. Entrar con tu correo

Te llega un código a tu correo. Solo pueden entrar los correos que el dueño agregó en Supabase (Authentication → Users).

Barra: avance real; la rayita negra marca lo planeado a hoy. Reglas del estado: 🔴 permiso o tarea crítica vencida, más de 10 % vencidas o más de 15 días de retraso contra la línea base · 🟡 vencidas, bloqueos, decisiones pendientes o algo crítico que vence en 7 días · 🟢 lo demás.

Compartir

Agrega el correo y su rol. «Lector» ve el tablero; «editor» además lo actualiza. Antes, el correo debe existir en tu proyecto Supabase (Authentication → Users → Add user). Para quitar el acceso, quítalo aquí: deja de ver el plan en su siguiente consulta (lo que ya imprimió o descargó no se borra).

📘 Guía paso a paso para el dueño (una sola vez)
  1. Entra a supabase.com/dashboard con tu cuenta y pulsa New project. Nombre: «dominus-cartera». Región: la más cercana (por ejemplo, East US). Guarda la contraseña de la base de datos en tu gestor de contraseñas (no la escribas en DOMINUS). Espera a que el proyecto quede listo (1–2 minutos).
  2. Menú izquierdo → SQL Editor → New query. Pulsa abajo «Ver SQL», cópialo completo, pégalo y pulsa Run. Debe decir «Success». Se puede volver a ejecutar sin perder datos.
  3. Authentication → Sign In / Providers: deja activado Email. En Authentication → Emails → Magic Link (plantilla del código), agrega {{ .Token }} en el cuerpo para que el correo traiga el código de 6 dígitos.
  4. Authentication → Users → Add user → Send invitation (o «Create new user»): agrega tu correo y el de cada directivo o editor. Esta página no crea usuarios sola.
  5. Correo para personas fuera de tu equipo: el servicio de correo incluido en Supabase solo envía a los miembros de tu organización y con límites bajos. Para tus directivos configura un SMTP propio en Authentication → Emails → SMTP Settings (por ejemplo, el correo de tu empresa o un servicio como Resend o Brevo; revisa sus límites y costos).
  6. Project Settings → API Keys: copia la Project URL y la publishable key. Pégalas arriba en «Conectar el proyecto». Nunca copies la «secret» ni la «service_role».
  7. Entra con tu correo y el código. En «Agregar un plan a la cartera» sube cada plan con su empresa y sector. Abre el plan → «Actualizar y compartir» → comparte con el correo del directivo como «Lector».
  8. Pulsa «Copiar enlace de este plan» (o de la cartera) y mándaselo. El directivo lo abre, escribe su correo, recibe el código y ve el tablero. La página se actualiza sola cada minuto cuando tú vuelves a subir el Excel.
  9. Cada vez que actualices el Excel: abre el plan → «Actualizar con el Excel o JSON». Se guarda un corte automático para la gráfica de tendencia. Al aprobar el plan, pulsa una vez «Fijar línea base» para medir retrasos contra esa fecha.

El plan gratuito de Supabase tiene cuotas y pausa los proyectos sin actividad por varios días; revisa los planes vigentes. Conserva tus Excel como respaldo. Seguridad: Row Level Security · acceso por código.
