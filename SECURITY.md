# Política de seguridad

## Cómo reportar una vulnerabilidad

Escribe a **contacto@dominusosint.com** con el asunto «Seguridad» o usa «Report a vulnerability» en la pestaña *Security* de este repositorio (reporte privado). No abras un issue público.

Incluye qué encontraste, cómo reproducirlo y su impacto. Respondemos en un máximo de 5 días hábiles.

## Alcance

- El sitio (dominusosint.com y la copia en GitHub Pages), los Workers de Cloudflare (`cloudflare/`) y los flujos de GitHub Actions (`.github/workflows/`).
- Fuera de alcance: ataques de denegación de servicio, ingeniería social y pruebas contra servicios de terceros (Cloudflare, GitHub, Supabase, Mercado Pago).

## Reglas

- No accedas, modifiques ni borres datos de otras personas.
- Danos tiempo razonable para corregir antes de publicar.
- Las pruebas de buena fe dentro de estas reglas no se persiguen.
