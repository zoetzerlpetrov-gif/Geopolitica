Herramientas locales y límites

F049: importa XML de Nmap/Greenbone y JSON de ZAP/SARIF; los archivos se procesan en este navegador. No se ejecutan escaneos.

F052: en tu equipo ejecuta python tools/fase2/inspeccionar.py https://tu-dominio.example --autorizado --salida servicio.json e importa el JSON en TLS y cabeceras. Consulta un servicio HTTPS; no sigue redirecciones ni descarga cuerpos.

F043: python tools/fase2/multimedia.py archivo.jpg --salida multimedia.json. Genera SHA-256 e incorpora metadatos de exiftool y validación de c2patool si están instalados. La confianza del certificado requiere configuración de anclas; revisa el informe original.

Las consultas automatizadas de registros, seguimiento periódico, almacenamiento compartido y secretos de APIs requieren backend. Las fichas documentales y revisiones funcionan aquí sin registro. EPO OPS necesita registro para su API; esta fase permite documentar resultados consultados o aportados.
